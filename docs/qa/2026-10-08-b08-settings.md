# B08：統一設定窗口與 AI 連接測試

日期：2026-10-08。基線：`367578f`。本批不修改資料格式，也不開啟真實詞庫的 V3 遷移。

## 本批交付

隔離 V3 使用唯一的 macOS Settings 窗口，分為 General、Capture、Learning、AI、Data。側欄入口只打開此窗口，不改主窗口選中詞條、搜索、返回歷史或未保存草稿；舊窗口記住的 Settings 路由回退至首頁。捕獲與學習頁復用既有偏好和控制器，修改仍觸發備份；普通 V1/V2 保留既有頁面。

AI 頁顯示配置模型和獨立連接狀態。測試需要確認，只發一條固定公開 JSON 探針，不讀詞庫、不保存候選、不自動重試。重複點擊只啟動一個請求；取消、切頁或修改憑據後，遲到回應不能更新狀態。HTTP Retry-After 限制手動重試，錯誤摘要不含回應 body 或密鑰。QA UI 和 runtime 兩層禁用付費連接；live 驗證另走明確 opt-in。

共用 HTTP 客戶端的預設名稱改為 `deepseek-flash`，Settings 直接讀同一常量；thinking 仍為 disabled，JSON 契約、prompt 和輸出上限不變。這是更新官方請求名，不是重新評估語義品質。詳見 [AI 集成](../06-ai-integration.md)。

## 驗證結果

新增 16 項測試，覆蓋探針回應校驗、取消/單飛/憑據變更/安全錯誤/重試等待、設定路由保護和 opt-in live。所有命令均使用完整嚴格併發、併發警告及 warnings-as-errors。

| 範圍 | 結果 | 本機日誌 |
|---|---|---|
| 設定功能 V3 Debug 全套，改模型名前 | 1,225 項：1,218 通過、7 跳過、0 失敗 | `/tmp/wordnote-b08-settings-v3-debug.log` |
| 設定功能 V3 Release 全套，改模型名前 | 1,225 項：1,218 通過、7 跳過、0 失敗 | `/tmp/wordnote-b08-settings-v3-release.log` |
| 新模型名及受影響功能定向回歸，含一次 live | 35 項全部通過 | `/tmp/wordnote-b08-settings-flash-focused.log` |

全套的 7 個跳過是四個 live、兩個性能組及一個原生快捷鍵案例，不計作通過。改名後只補定向回歸，不重跑已完成的全版本矩陣。

```sh
RUN_LIVE_DEEPSEEK_CONNECTION_TEST=1 swift test --scratch-path .build-v3-qa \
  -Xswiftc -DWORDNOTE_V3_VALIDATION \
  -Xswiftc -strict-concurrency=complete -Xswiftc -warn-concurrency -Xswiftc -warnings-as-errors \
  --filter '(DeepSeekChatClientTests|DeepSeekConnectionProbeTests|LiveDeepSeekConnectionTests|AIConnectionTestControllerTests|LearningWorkspaceTests)'
```

本批共兩次獨立固定探針：改名前請求 `deepseek-v4-flash`，回報 `deepseek-flash`，約 0.434 秒；用戶要求更新名稱後，請求與回報均為 `deepseek-flash`，約 0.839 秒。均各一次、不重試，不包含私人內容。測試未暴露 token usage，費用未估算。這不是 60 例查詞品質評測。

## 原生界面與剩餘缺口

Computer Use 已核對側欄開啟標準 Settings 窗口（`com_apple_SwiftUI_Settings_window`），General 的五個頁籤及深色外觀控件顯示正常。Capture 頁操作使 Computer Use 回報 `native pipe closed before response`；受控重啟後仍重現，所以不反覆重試，也不據此斷言 App 崩潰。其餘頁籤交互尚未驗收。

B08 仍需完成可拖動布局、窗口寬度保存、三語文案與可訪問性，以及設定各頁和跨窗口偏好的原生回歸。README、介紹截圖及完整敏感資訊檢查仍留在代碼完成後的 C06。
