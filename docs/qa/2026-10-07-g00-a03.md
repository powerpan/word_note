## Reproducible Fixtures

```bash
./script/build_and_run.sh --ui-fixture populated light
./script/build_and_run.sh --ui-fixture populated dark
./script/build_and_run.sh --ui-fixture empty light
```

QA bundle 是 `com.powerpan.WordNote.UITest` / `WordNoteQA.app`，不關閉正常 WordNote 進程。它使用獨立偏好域及內存 store，不準備、遷移或讀寫正式 WordNote store；課程/詞條均為人工構造。分析通過離線 handler，Settings 的憑據文件指向獨立臨時目錄，不讀取正式 key。QA 分析是固定測試回應，不是模型品質證據。

以上是 G00 提交時的環境。2026-10-08 的 [A01 App 接入](2026-10-08-a01-app-integration.md) 將 QA store 改為帶 UUID session 的私有臨時持久庫，供恢復/重啟驗證；獨立 bundle、人工資料、離線 AI 與正式憑據隔離不變。省略 session 參數即新建測試會話，不復用正式資料。

樣本含 2 個課程、4 個詞條、3 個輸入、3 個待確認候選和 1 個復習事件，覆蓋長詞頭、多課程、中文單候選、重複候選與失敗輸入。

[固定 V1 資料庫](../../Tests/WordNoteCoreTests/Fixtures/README.md) 使用 SQLite backup API 導出，只含上述人工樣本。測試校驗固定 SHA-256，複製到臨時目錄後開啟，不改寫資源。後續模型變更不得重新生成 fixture 來掩蓋遷移問題。
