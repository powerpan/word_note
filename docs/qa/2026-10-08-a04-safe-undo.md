# A04 運行期單步安全撤銷

日期：2026-10-08（Asia/Hong_Kong）。基線：`9aacfde`，分支：`codex/supplemental-development`。這是 A04 子里程碑，普通 App 仍使用 V1，沒有啟用生產遷移。

## 範圍與邊界

- V2 的詞條、課程、候選編輯、課程成員關係、手動建詞與單/批次確認可記錄最近一次成功交易。
- 每個 V2 container 共用一份記憶體 history，跨窗口可見，但不跨 container、退出或重啟保留。沒有 redo、永久刪除、忽略或復習撤銷。
- 不回滾整库，只保存及反向處理受影響實體。已有詞的其他来源、無關後續編輯、查詢/復習事件不被撤銷刪除。
- 只使用內存與臨時 SQLite 合成 fixture；不讀寫真實詞庫，不修改 README、不製作介紹截圖、不提前執行 C06 全倉敏感資訊檢查，也不處理分發。

## 實作

| 組件 | 行為 |
|---|---|
| [UndoHistory](../../Sources/WordNoteCore/Domain/Services/V2/WordNoteV2UndoHistory.swift) | 局部 before/after receipt，只在保存成功後替換；幂等重送不製造新 receipt；operationID 防止舊窗口動作誤撤新保存 |
| [UndoCapture](../../Sources/WordNoteCore/Domain/Services/V2/WordNoteV2UndoCapture.swift) | 按 ID/外鍵/詞頭查詢，捕獲字段、revision、候選反向引用、来源/課程關係及 lookup/review 依賴；核對舊外鍵、名稱與關係 ID 所有者 |
| [UndoApply](../../Sources/WordNoteCore/Domain/Services/V2/WordNoteV2UndoApply.swift) | 驗證完成後一次交易回寫；只刪那次新建的詞/課程/關係，不做一般級聯刪除；還原後 revision 繼續增加 |
| [UI 入口](../../Sources/WordNote/Presentation/SavedChangeUndoControls.swift) | QA 工具列圖標及 Edit 菜單；先處理本窗口草稿，不接管文字輸入的 Command-Z；restore 期間禁用 |

後續編輯、來源/候選引用、精確重查、復習、外鍵刪除、被還原詞頭已占用或關係 ID 被他詞使用，均阻止整次撤銷，不做部分回退。資料衝突使已失效 receipt 清空；保存失敗、恢復屏障及直接模型未保存修改保留 receipt 供重試。另一操作已替換 history 時，舊操作 ID 只拒絕本次動作，不清除新的 receipt。

捕獲物使用既有 snapshot DTO，但只是局部資料，不能送入完整快照恢復。現有可撤銷交易只新增/刪除關係，不編輯既有 occurrence/link 字段；日後若擴充此類編輯，須同步擴充還原及依賴測試，不可直接復用現在的關係還原邏輯。

`WordNoteCore` 單一 target 啟用 `InferSendableFromCaptures`，配合 Foundation Predicate 的 Sendable key path 推斷；保留完整嚴格並發與 warnings-as-errors，沒有關閉警告或把 SwiftData 模型標成 unchecked Sendable。本輪使用本機 Swift 6.4/SDK 27，未驗證舊工具鏈兼容性；package deployment 仍是 macOS 14、語言模式仍為 Swift 5。

## 自動化與實機狀態

[31 項撤銷測試](../../Tests/WordNoteCoreTests/WordNoteV2UndoTests.swift) 包含：

- 詞条字段與課程關係、同来源多候選編輯、手動建詞、新詞確認、關聯既有詞、課程新增/編輯、批次確認。
- revision 繼續增加、只撤最近一次成功保存、無關修改保留、保存失敗保留上一筆 history。
- 新詞/舊詞之後被精確重查或復習、候選反向引用但 Term revision 未變、批次中只有一詞產生依賴時仍拒絕全部撤銷。
- 舊詞頭被占用、舊課程刪除、關係 ID 轉屬、新課程已被使用、目標被刪除不復活。
- 撤銷保存失敗回滾已刪實體/關係、counter/date 異常、restore 屏障、直接模型草稿、跨容器及重啟歷史隔離。
- 临時 SQLite 保存後釋放並重開，完整 DTO 一致，撤銷歷史不持久化。
