# V3 隔離 App 與復習界面接入

日期：2026-10-08。基線：`c248c62`，本記錄隨本次 V3 UI 里程碑提交。適用：WN2-B03/B04/B05/B06，B07 首頁統計先行接入；QA-20 至 QA-27 的部分集成與原生證據，不代表整個 B 階段通過。

## 邊界

- 普通入口仍為 V1，`--ui-v2-fixture` 仍為 V2；新增 `--ui-v3-fixture`，不升級真實詞庫。
- `WORDNOTE_V3_VALIDATION` 與 `WORDNOTE_V2_VALIDATION` 互斥。版本化 App 必須具備 QA bundle 身份和 fixture 參數，沒有回退到正式資料目錄的路徑。
- QA 使用 `offline-ui-fixture`，本批沒有付費請求；前批兩次 DeepSeek live 證據不等於本批 UI 執行了真實網絡調用。
- 沒有改凍結 V1/V2 schema、codec 或 fixture。沒有分發、簽名、公證、合併 main 或真實資料遷移。
- README/項目介紹截圖/完整工作樹、暫存區、可達歷史敏感資訊審查仍留待 C06。

## 實作

1. `VersionedValidationRuntime` 在完整啟動驗證後只建立一份 queue、資料保護、Undo history、capture context、navigator、panel 和快捷鍵；三個捕獲入口共用相同 queue。V3 啟動修復走 `inspectV3Repair`。
2. App-only 型別別名選擇 V2/V3 模型與 writer。現有 Inbox、候選預覽、內容編輯、多課程整理、CSV、浮窗和備份頁重用版本化流程，不把 V2 writer 接入 V3 store。
3. V3 不編譯舊 ReviewView/legacy ReviewService。每個 Review surface 自持 `V3ReviewController`；持久會話由唯一正式作答服務負責，窗口只持有短期 lease、輸入、正面/揭示背面及預覽。
4. 明確開始、繼續、暫停、結束固定組；切頁/失焦/關閉/恢復開始清除回答權與答案，不重建持久隊列。回來需再次繼續、揭示；另一 owner 不能搶答。
5. 揭示後顯示四種反饋及排程間隔。Skip/Later/等待/不可用/完成分開計數；等待時只嘗試呈現已到時的本組項，不追加新卡。正面只使用 `ReviewQuestionFront`，不拿整個 Term 作題面。
6. 新增原句填空 sheet：選原始 capture、指定原文中的答案形式和完整匹配位置、可接受答案、先預覽再建卡。服務核對原始記錄/來源/hash/revision；單詞頭或中文來源不能硬生成句子。比對答案只提供提示，不自動評分。
7. 詞庫閱讀頁展示各方向卡片的 state/mastery/due/burial/priority，可明確啟用方向、停卡、恢復及建填空卡。填空恢復沿用同一 card/target，保留能力、配額、歷史及曝光，不復活已失效會話項；來源刪除/改寫後不得恢復。僅刪 Inbox 原始記錄、仍保有已驗證 occurrence 的卡可恢復，不混淆兩種刪除。V3 撤下舊 Term mastery 篩選和編輯，歷史計數放到 disclosure，不用兼容值冒充當前卡片能力。
8. 首頁改用共用 V3 統計：可用/新卡/等待、當日不同卡、作答次數、成功完成、首次回憶分子/分母及繼續組入口。課程學習頁及具體條目深鏈屬 B07 後續，不標為完成。
9. Settings 增加組大小和每日新卡限額，建立新組時凍結並限制在核心範圍。這兩項目前僅本機 UserDefaults；偏好備份白名單、統一 Settings window 及三語仍是 B08 必做出口。

## 原生問題與修復

- 首次嚴格編譯拒絕 `NSEvent` 跨 `MainActor.assumeIsolated` 返回。改為僅跨出 Bool 消費結果，事件保持在同步原生回調內；沒有 `@unchecked Sendable`。
- 實機發現確認結束時 sheet 令主窗口失焦，原 guard 靜默拒絕命令。結束命令改為確認後重新取得共享 lease，不要求主窗口當刻為 key；仍受可用性/另一窗口 ownership 約束，不能產生作答事件。新增兩項回歸，重跑實機確認後顯示 `Group ended`。
- 圖標 Menu 被系統撐滿橫條。詞庫導出和啟用方向菜單改為有固定寬度的 borderless icon menu。
- 收尾復核發現填空卡停用後沒有恢復入口，而且同目標重建會被去重拒絕。補上 `resumeClozeCard` 交易和 Enable 操作，重新校驗題面/hash/版本；未引入卡恢復為 new，已有學習歷史恢復為 review 並繼承曝光邊界，沒有偽造新卡或答題事件。
- 鍵盤橋接是 App 內 local monitor，不是系統全鍵盤監聽。非本窗口、sheet/modal、文字 responder、修飾鍵、autorepeat 均不處理；空格僅揭示，1-4 僅已揭示後評分，Return 無評分綁定。
