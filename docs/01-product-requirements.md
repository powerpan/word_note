# 01. Product Requirements

## 產品一句話

Word Note 是一個面向 AI / CS 英文授課場景的 macOS 個人專業英語詞彙工具，用於快速記錄英文內容或查找中文意圖對應的英文表達，通過 AI 產出值得學習的英文詞、短語、術語和表達，並沉澱成本地可復習詞庫。

## 目標用戶

核心用戶是中文母語、正在英文授課環境中學習 AI / CS 的研究生。

典型特徵：

- 有一定 AI / CS 基礎，但對英文課堂中的專業詞彙反應速度不夠快。
- 需要理解詞彙在 AI / CS 語境中的含義，而不只是普通詞典釋義。
- 常在課堂、論文、課件、作業和教材中遇到新詞。
- 需要記錄的內容包括單詞、短語、術語、固定表達和有價值的句型。
- 更需要個人積累工具，而不是通用詞庫或社交型背單詞產品。

## 核心問題

用戶在英文授課和英文材料閱讀中有三個直接痛點：

1. 記錄成本高：上課或閱讀時不希望中斷當前任務去查詞、填字段或整理筆記。
2. 普通詞典不夠專業：例如 `bias`、`loss`、`token`、`head` 在 AI / CS 語境中有特殊含義。
3. 只記錄不復習：臨時查過的詞容易遺忘，沒有形成可搜索、可回顧、可復習的個人詞庫。

## 產品目標

首版產品要完成一個可靠的個人學習閉環：

```text
輸入英文內容或中文查英文意圖
  -> 保存原始記錄
  -> 調用 AI 解析
  -> 展示候選詞條
  -> 用戶確認和編輯
  -> 保存到本地詞庫
  -> 進入復習隊列
```

## 非目標

首版不做以下方向：

- 用戶賬號和登錄註冊。
- 雲同步、多端同步、iCloud 同步。
- 社區詞庫、分享、排行榜、社交功能。
- 完整 PDF 閱讀器或課件閱讀器。
- 錄音轉文字或課堂實時字幕。
- 支付、訂閱和會員系統。
- 大型知識圖譜或自動課程知識庫。

這些能力可以在核心閉環穩定後重新評估。

## 核心場景

### 上課快速記錄

用戶聽課時遇到不熟悉的術語，例如：

```text
regularization
latent representation
gradient descent
attention mechanism
inductive bias
```

要求：

- 可在主窗口中快速輸入。
- 只填 raw text 即可保存。
- 課程、來源、備註可選。
- 保存後可以立即解析，也可以稍後整理。
- 任何 AI 失敗都不丟失原始輸入。

### 閱讀論文 / 課件記錄

用戶複製一句話：

```text
The model learns a latent representation of the input data.
```

App 應：

- 保留完整原句作為上下文。
- 解釋整句含義。
- 優先提取 `latent representation`。
- 可以提出 `input data` 等低優先級候選。
- 不應機械解釋 `the`、`a`、`of` 等功能詞。

### 課後整理

用戶打開未整理記錄：

- 查看 AI 解析結果。
- 勾選要保存的候選詞條。
- 修改中文解釋、英文解釋、AI / CS 語境說明、例句。
- 忽略低價值候選。
- 重新生成解析。

### 長期復習

用戶定期查看今日待復習：

- 英文看中文。
- 中文想英文。
- 查看上下文提示。
- 根據「完全不會 / 模糊 / 記得 / 很熟」更新掌握狀態和下次復習時間。

## 產品原則

### 快速記錄優先

上課和閱讀時的第一任務是不中斷當前學習。首版不要求用戶在記錄時補齊所有字段。

### 短語優先

AI / CS 中大量概念以短語出現，例如：

- loss function
- latent representation
- attention mechanism
- gradient descent
- feature extraction
- inductive bias
- hidden state

短語應作為整體優先解釋，不應默認拆成多個普通單詞。

### 詞本義優先，專業語境補充

解釋應先給出詞語本身的常用含義。普通詞如果在 AI / CS 中有特殊含義，再補充專業語境，不能每個詞都硬套「在 AI 語境中」。例如：

| 詞 | 普通含義 | AI / CS 語境 |
|---|---|---|
| loss | 損失 | 損失函數的值 |
| bias | 偏見 | 模型偏差 / inductive bias |
| layer | 層 | 神經網絡層 |
| head | 頭 | attention head |
| token | 標記 | NLP 模型處理單位 |
| mask | 面具 | attention mask / segmentation mask |
| prompt | 提示 | 大模型輸入指令 |
| agent | 代理 | 智能體 |

### 用戶掌控 AI 結果

AI 只提供候選和初稿。最終保存什麼、如何解釋、是否進入詞庫，由用戶決定。

### 本地優先

詞庫是個人學習資料，首版以本地保存為主。除 AI 解析請求外，不主動向外部服務傳輸資料。

## 主要功能

### Quick Add

- 輸入英文單詞、短語、句子或短段落，也可輸入中文詞義或表達查找英文。
- 選擇課程，可留空。
- 選擇來源：class、paper、slides、assignment、book、other。
- 填寫備註，可留空。
- 支持「保存」和「保存並解析」。
- 主 Quick Add 和浮窗 Quick Add 使用現有正式詞庫提供本地前綴補全。
- 補全只以灰色後綴提示；用戶按 Tab 接受，按 Enter 或保存按鈕才提交。
- 保存並解析前檢查正式詞庫是否已有完全相同的 normalizedTerm。
- 若命中已有詞條，跳過 DeepSeek，直接展示既有釋義並將該詞加入今日復習。
- 中文輸入自動切換為中文查英文，不走英文 term 精確命中短路，仍建立 Inbox 記錄等待確認。

### AI Analysis

- 判斷輸入類型：word、phrase、sentence、paragraph。
- 生成整句或原文含義。
- 提取值得學習的候選詞條。
- 為每個候選提供中文解釋、英文定義、AI / CS 語境說明、例句、相關詞。
- 中文查英文時 `term` 必須仍為英文主體，中文原文只作為 InputRecord 上下文，中文釋義保存在 `chineseMeaning`。
- 返回結構化 JSON。
- 支持解析失敗後重試或手動補充。

### Candidate Review

- 展示原始輸入、整句含義和候選詞條。
- 默認勾選高價值候選。
- 支持逐項編輯。
- 支持忽略候選。
- 支持保存所選候選到詞庫。

### Vocabulary

- 詞條列表、詳情、搜索、編輯、刪除。
- 英文 term 和英文定義支持大小寫不敏感的包含搜索；中文釋義支持簡繁規範化後的子串搜索。
- 按課程、來源、詞條類型、掌握程度、重要度篩選。
- 支持保存候選時的重複詞條提示。
- P1 支持候選合併到已有詞條。

### Courses

- 新增、編輯、刪除課程。
- 將 InputRecord 和 Term 綁定到課程。
- 查看課程下詞條和待復習數量。

### Review

- 今日待復習。
- 按課程復習。
- 基礎卡片。
- 記錄復習結果。
- 支持中文 -> 英文、快捷鍵、本輪統計和簡化自適應排程。
- 再次輸入已存在詞條時，將其視為需要優先復習的薄弱詞。

### Settings

- 外觀模式：跟隨系統、淺色、深色。
- DeepSeek API Key 管理。
- 默認課程。
- 默認來源。
- 資料導出放入後續版本。
- 復習規則配置在 P1 後評估。

## 成功標準

首版成功不是功能數量多，而是以下流程順暢：

1. 用戶能在 5 秒內保存一條原始英文內容。
2. App 能可靠調用 AI 並返回可用候選。
3. 用戶能清楚看到哪些詞條值得保存。
4. 保存後的詞條可被搜索、編輯和復習。
5. 即使 AI 失敗，原始輸入也完整保留。
